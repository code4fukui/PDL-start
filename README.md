# PDL-start

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

PDL-start is a tool to assist in the creation of administrative open data license agreements.

## Features
- Generates a license agreement based on user input
- Includes options for noting third-party rights and content usage restrictions

## Usage
1. Enter the name of the administrative body
2. Check the relevant options
3. The license agreement text will be generated in the text area
