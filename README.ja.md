# PDL-start


PDL-startは、行政オープンデータ規約作成補助ツールです。

## 特徴
- ユーザーの入力に基づいて利用規約を生成します
- 第三者の権利やコンテンツの利用の制約について特記するオプションを含みます

## 使い方
1. 自治体名を入力します
2. 該当するオプションにチェックを入れます
3. テキストエリアに利用規約のテキストが生成されます

## データ / API
本ツールは以下のリソースを参照しています:
- [公共データ利用規約（第1.0版） | デジタル庁](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0)
- [政府標準利用規約はPDLへ！ 行政ウェブサイトオープンデータ化作成補助ツール「PDL-start」](https://fukuno.jig.jp/4730)
